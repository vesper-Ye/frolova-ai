# 🌸 弗洛洛 （Frolova) 专属 AI 聊天助手

> *"（她缓缓抬起眼眸，彼岸花的影子在眼底一闪而过）你来了。这里的风，还带着上一个世界的气息。"*

这是一个基于大语言模型（LLM）打造的全栈 AI 角色扮演聊天应用。界面以《鸣潮》中的角色“弗洛洛”为主题，拥有沉浸式的动态背景、优雅的排版，并支持**多话题独立记忆**与**联网搜索**。

无论你是零基础的小白，还是硬核开发者，都可以通过下方的“一键启动包”或“源码部署”快速与她见面。

---

## ✨ 核心特性

- **🎭 极致沉浸**：全屏动态呼吸背景、彼岸花瓣飘落特效、火星余烬粒子效果。
- **🧠 独立长期记忆**：内置左侧侧边栏，支持多话题独立存储（基于浏览器 LocalStorage），你们的每一次对话都被温柔保存，互不串线。
- **📝 智能排版**：动作/神态描写自动变为浅灰色斜体，台词保持亮白色正体，阅读体验极佳。
- **🌐 自主联网搜索**：内置 OpenRouter 联网工具，遇到实时信息时，她会自主搜索并用诗意的口吻转述，拒绝 AI 幻觉。
- **🔄 模型自由**：前端自动获取 OpenRouter 当前可用的免费大模型，随时切换。
- **🔒 隐私安全**：API Key 完全保存在本地（`API_KEY.txt`），不经过任何第三方服务器。

## 🚀 极速体验（推荐普通玩家使用）

如果你想直接和她聊天，不需要懂任何代码，请按照以下步骤操作：

### 1. 下载一键启动包
前往本仓库的 **[Releases](https://github.com/vesper-Ye/frolova-ai/releases)** 页面，下载最新版本的 `.zip` 压缩包并解压。

### 2. 获取你的专属 Key
1. 访问 [OpenRouter 官网](https://openrouter.ai/) 注册账号。
2. 生成你自己的免费 API Key（以 `sk-or-v1-` 开头）。
3. 打开解压文件夹里的 `API_KEY.txt`，将 Key 粘贴进去，保存。

### 3. 双击启动
双击文件夹里的 **`一键启动.bat`**。
等待几秒钟，浏览器会自动弹出网页，直接开始沉浸式聊天！

*(详细常见问题请参考文件夹内的 `使用说明.txt`)*

## 🛠️ 技术栈
前端: 原生 HTML / CSS / JavaScript (无框架，轻量极速)

后端: Node.js / Express

AI 核心: OpenRouter API (支持免费及付费模型切换)

## ⚠️ 常见问题排雷
网页提示 401 Missing Authentication header：说明你的 API_KEY.txt 填错了，里面可能包含了中文或多余的空格，请确保只有一串 Key。

黑框框提示 429 或 503：说明当前免费模型节点被挤爆了。请在网页右上角的设置里，切换为 openrouter/free（自动路由），或者等几分钟再试。

如何彻底关闭：关闭网页后，直接关掉后台那个黑色的命令提示符窗口即可。
